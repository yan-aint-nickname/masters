# Программирование на Python

Учебные задания по Python. Домашнее задание №3 посвящено сбору данных о книгах
с Books to Scrape, запуску по расписанию и тестированию парсера.

## Окружение и зависимости

Для управления Python, зависимостями и изолированным окружением используется **Pixi**.
Отдельно устанавливать пакеты через `pip` или создавать окружение через `conda`
не требуется.

- `pixi.toml` описывает зависимости и поддерживаемые платформы.
- `pixi.lock` фиксирует версии пакетов для воспроизводимой установки.
- `.pixi/` содержит локальное окружение и исключена из Git.

Текущая конфигурация рассчитана на **macOS с Apple Silicon (`osx-arm64`)**
и Python 3.14. Для выполнения команд нужен установленный Pixi.

Из корня репозитория перейдите в папку проекта и установите окружение:

```bash
cd programming_python
pixi install --locked
```

Флаг `--locked` использует зафиксированные зависимости и проверяет согласованность
`pixi.lock` с `pixi.toml`. Все последующие команды выполняются из папки
`programming_python`. `pixi run` запускает их в окружении проекта.

В задании используются `requests` для HTTP-запросов, `beautifulsoup4` для разбора
HTML, `schedule` для расписания, `pytest` для тестов и `jupyterlab` для блокнотов.

## Использование парсера

Откройте Python в окружении проекта:

```bash
pixi run --locked python
```

Выполните пример, который собирает первую страницу каталога и сохраняет результат
в `artifacts/books_data.txt` в формате JSON:

```python
from pathlib import Path

from scraper import HttpClient, Scraper

scraper = Scraper(HttpClient())
data = scraper.scrape_books(
    is_save=True,
    left=1,
    right=2,
    catalogue="books_1",
    filepath=Path("artifacts/books_data.txt"),
)
```

`left` и `right` задают диапазон страниц; правая граница не включается.
При `is_save=False` метод возвращает данные без записи в файл.
Возвращает словарь, где ключом служит URL категории, а значением - список книг.
Для сбора данных нужен доступ к сайту Books to Scrape.

## Запуск тестов

```bash
pixi run --locked python -m pytest tests -q
```

Тесты находятся в `tests/test_scraper.py`. HTTP-клиент в них подменяется моком,
поэтому запросы к сайту не отправляются.

## Файлы проекта
